# LK Design and Build — which logo file to use

Generated by `generate_logo_pack.py`. Re-run it if any approved logo changes.

---

## Why the old files looked wrong

Two separate problems, and only one of them is actually blur.

**1. Every file in `assets/branding/final/` stores the logo as live text.** All 26
of them set the LK in Courier New and the tagline in Inter and expect those fonts
to be installed. Courier New usually is. **Inter usually is not.** On a machine
without it, the tagline silently falls back to Helvetica or Arial: different
letterforms, different width, no warning, no error. The logo is not blurry, it is
simply not the logo. Those files are fine as web assets on a site that loads Inter
itself, and should never be sent to anyone else.

**2. The only ready-made images were PNGs at 2400 px wide.** That is enough up to
about 200 mm at full print resolution. Dropped onto an A3 sheet at full width it
lands at roughly 205 dpi, which is where the softness comes from. Scaling a PNG up
never adds detail back.

Everything in this folder is **converted to outlines**, so it needs no fonts at
all and cannot substitute. The output was pixel-checked against every approved
file: all 24 logo lockups render identically.

## Which file to use

| You are doing this | Use this |
|---|---|
| Placing the logo in a DWG / AutoCAD title block | `dxf/` — real CAD geometry |
| A3 sheet, any printing | `pdf/` — vector, sharp at any size |
| Supplying a printer, signwriter, embroiderer | `pdf/` (or `apparel/` for shirts) |
| Word, Canva, PowerPoint, email signature | `png-4000/` if it will be printed, `png-1200/` for screen only |
| Website, Figma, anything that takes SVG | `svg/` |
| Shirts, caps, workwear | `apparel/` — see below |
| Social post, slide background | `png-1200/` |

**The rule of thumb:** if it is going to be printed or cut or stitched, send the
PDF. If the software will not take a PDF, send the 4000 px PNG. Never send a
screenshot, and never scale a PNG up.

### Does a PDF work for CAD and for apparel?

**For apparel, yes.** Embroiderers and screen printers both ask for vector, and
their list is almost always "AI, EPS or PDF". They open it in Illustrator or
CorelDRAW and work from there. Because the type is outlined there is no font to
go missing at their end, which is the usual reason a logo comes back wrong. For
embroidery they then *digitise* it into a stitch file (DST, EMB, PES); that is
their job, not something you supply. It is normally a one-off fee, and it is
worth asking them to send you the stitch file afterwards so another shop can
reuse it rather than charging to digitise from scratch.

**For a DWG, not really.** AutoCAD can attach a PDF as an underlay or run
PDFIMPORT to convert it, but underlays do not plot predictably and PDFIMPORT
produces a loose pile of geometry with no layer structure. That is why `dxf/`
exists: native CAD geometry, organised on layers.

### CAD and drawing sets

Use `dxf/`. Four lockups, including the K-gold two-tone already in use on the
drawings.

- Closed LWPOLYLINEs plus solid HATCHes, so it plots correctly and stays
  editable.
- Layers by brand colour with the true colour set on the layer: `LK-CHAMPAGNE`,
  `LK-GOLD`, `LK-CHARCOAL`, each with a matching `-FILL` layer.
  **Freeze the `-FILL` layers for a line-only logo.**
- Drawn so the artwork box is 100 mm wide, file units set to millimetres, so it
  inserts at a sensible size and scales cleanly.
- Curves flattened at 24 segments each, far finer than any plotter resolves.

### A3 and other printing

Use `pdf/`. It is vector, so it is as sharp on an A3 title block as on a business
card, and the file is a few kilobytes.

If a program refuses PDF, `png-4000/` covers the full width of an A3 sheet at
342 dpi, comfortably above the 300 dpi print standard. The PNGs have transparent
backgrounds, so they sit on any colour.

For a drawing title block, `lk-logo-horizontal-charcoal` is usually the right
shape. For a cover sheet, `lk-logo-charcoal` (stacked) or `lk-logo-letterhead-charcoal`.

## Shirts and workwear

Send the embroiderer or printer a file from `apparel/`. These are one colour,
fully solid, with no transparency and no background panel, which is what both
processes need. The gold in the standard files is set at 90% opacity, and a
screen printer cannot print 90% of an ink.

Ask for a thread or ink match to **Pantone 465 C** for the gold, and ask for a
sew-out or a proof before the full run.

### Minimum sizes

The binding constraint is the thinnest stroke in the artwork. Embroidery needs
about 0.8 mm to hold a stitch; screen print holds about 0.3 mm. Measured from the
actual outlines:

| Lockup | Embroidery | Screen print | Limited by |
|---|---|---|---|
| Stacked (`lk-logo-1colour-*`) | 183 mm wide | 69 mm wide | the tagline |
| Horizontal (`lk-logo-horizontal-1colour-*`) | 145 mm | 54 mm | the tagline |
| LK mark only (`lk-icon-1colour-*`) | 49 mm | 18 mm | the mark |

**What this means in practice.** A left chest is typically 80 to 90 mm wide.

- **Embroidered left chest: use the LK mark on its own.** The full lockup needs
  145 mm before the tagline will stitch cleanly, so at left-chest size DESIGN AND
  BUILD will fill in and turn into a smudge. This is a property of the tagline
  being light and widely spaced, not a fault in the file.
- **Embroidered back or front of a hoodie:** 250 to 300 mm wide, so the full
  stacked lockup is fine and will look excellent.
- **Screen-printed left chest: the full lockup is fine** at 80 to 90 mm. Screen
  print holds much finer detail than a needle does.
- **Caps:** mark only. There is not enough room for anything else.

## What not to use

- Anything in `assets/branding/final/*.svg` — font-dependent, see above.
- `og-image.*` — 1200 x 630 px, built for a social share card. It will look
  terrible printed at any size.
- Anything pulled off the website with a right-click, or screenshotted.
- The old PNGs in `assets/branding/final/png/` — superseded by `png-4000/`.

## One fix applied on the way through

`lk-icon-two-tone.svg` still carried the letter-spacing bug that was fixed for
the horizontal K-gold logo in commit `c698c5b`: when the L and K are split into
separate coloured pieces, the tightened letter-spacing stops applying across the
join, so the mark renders about 2.6 units too wide. The outlined version in this
pack matches the single-colour icon exactly. Worth fixing in the source file too.
